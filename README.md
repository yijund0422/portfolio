# Learning Designer Portfolio

This repository contains a simple static website that you can use as a
starting point for showcasing your work as a learning designer. The site is
aimed at tech companies and highlights your background, projects, and contact
information.

## Getting Started

Open `index.html` in your web browser to view the site locally. You can edit
the HTML and CSS files to personalize the content, add more projects, or
change the styling.

## Customization Tips

- Replace placeholder text (like `Your Name` and `your.email@example.com`) with
  your own information.
- Update the **Projects** section with examples of your instructional design
  work.
- Modify `style.css` to change the site's look and feel.

Feel free to expand the project with additional pages or scripts to further
showcase your skills.
